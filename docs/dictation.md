The Posts is a blog system near to a CMS.
===

# 概要

 - 疎結合なシステム
    - コンテンツを管理・生成するモジュールは分けれる
 - どこへコンテンツを生成するかは、モジュールの自由
    - 直接、公開ディレクトリにコンテンツを生成
    - 非公開の確認用ディレクトリに生成
    - 公開環境へ同期する為のステージングディレクトリに生成←これをRsyncやFTPで同期することもできる
 - 何をコンテンツとして生成するか、モジュールの自由
    - JSON→ブラウザで組み立てる
    - HTML→完全に静的なページ
    - shtmlでサーバーサイドインクルード
 - cronでスケジュール
    - 指定時間になったらコンテンツを生成
    - RsyncやFTPで同期

# ルール

疎結合で破綻しないようルールをしっかり作る。

# 既存システムの問題点

## MovableType

 * 権限管理が後付： 一人でコンテンツを書いて、すぐ公開する前提だった
 * スケジュール公開が後付： 複数スケジュールの公開に対応できない。即時公開と時間指定公開が混じる

 * 
 * 

# WordPress

 * コンテンツが動的に生成される
    * 攻撃に弱い、脆いので、公的機関では使えない
    * サーバー負荷が高め
